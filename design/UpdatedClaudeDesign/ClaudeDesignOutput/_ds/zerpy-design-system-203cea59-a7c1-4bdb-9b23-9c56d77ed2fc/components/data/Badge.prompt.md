Status on a row, a card or an event — one word, never a sentence.

```jsx
<Badge tone="success">Confirmed</Badge>
<Badge tone="warning">Tentative</Badge>
<Badge tone="neutral" dot={false}>Draft</Badge>
```

Semantic tones only. Never carry identity in a Badge — a class or faction is a Tag with a rail. The tones are the only meaning colors have here: green is confirmed, amber is pending, red is failed, blue is informational.
