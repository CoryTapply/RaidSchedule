100×100 square. The rail bleeds top and bottom — give the mark zero vertical padding and set its height, not its width. Horizontal padding is free. All geometry is rects and polygons, so there is no font dependency. Never recolor the letter: it is #f2f1fb on dark and #0b0c14 on light.

On a web page the default is a header lockup: the letter spans the heading and subheading exactly — its top on the heading’s cap line, its bottom on the subheading’s baseline — while the rail bleeds past both. The letter occupies the middle 56% of the square, so set mark height = 1.77 × the text block height, then nudge it down by 3% of that height. For a 32px heading over a 19px subheading that is 111px, top: 3px. Gap is 20–22px. With no subheading, size the letter to the heading’s cap height alone.
